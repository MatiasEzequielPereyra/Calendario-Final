QUINTA MEWEN - CALENDARIO DE RESERVAS

CAMBIOS:
1. Viernes, sábado y domingo admiten DOS reservas independientes por fecha.
2. Turno 1: 10:00 a 17:00.
3. Turno 2: 22:00 a 05:00 del día siguiente.
4. El formulario obliga a seleccionar el horario.
5. Si un turno está ocupado, queda bloqueado y el otro sigue disponible.
6. No se permiten reservas lunes, martes, miércoles ni jueves.
7. El calendario muestra ambos turnos y cuáles están ocupados.
8. Se mantiene el login:
   Usuario: quintaMewen
   Contraseña: Quinta123.!

SUPABASE:
Ejecutá supabase_horarios.sql en el SQL Editor de Supabase antes de usar la nueva versión.

IMPORTANTE:
La reserva nocturna 22:00-05:00 se guarda con la fecha en la que comienza. Ejemplo:
Viernes 22:00 -> sábado 05:00 = fecha del viernes + horario 22:00-05:00.
